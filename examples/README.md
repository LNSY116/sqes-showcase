# 公開展示用虛構資料

[回到專案首頁](../README.md)

`synthetic-cases.json` 內的六筆案例均為人工編造，不是由真實客戶資料替換姓名、抽樣或改分產生。顧問使用「示範顧問 A／B／C」代號，不對應任何實際員工。

| 欄位 | 意義 |
| --- | --- |
| case_id | 公開示意案例編號 |
| advisor | 虛構顧問代號 |
| review_status | 示意工作流程狀態 |
| illustrative_quality_score | 0–100 的示意品質指標，非實際規則運算結果 |
| illustrative_intent_score | 0–100 的示意意向指標，非成交機率 |
| focus | 人工編造的關注主題 |
| illustrative_dimensions | 六個獨立示意面向分數，非實際量規，不用於計算總分 |
| fictional_customer_quote | 另行撰寫的虛構顧客發言 |
| illustrative_follow_up | 依虛構情境撰寫的跟進方向 |

此資料刻意使用簡化格式，不是完整應用程式的匯入格式或內部資料結構。不得據此推算實際配分規則、模型表現或員工績效。

展示圖共有六筆案例，四筆標為「複核完成」，兩筆標為「待複核」。所有分數僅供表達畫面概念；待複核案例不列入正式排名。

互動看板的平均值與顧問比較只計入目前篩選內「複核完成」的案例。下載按鈕匯出目前篩選結果，包含明確的虛構資料標示。
